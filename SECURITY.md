# Security and local game data

This launcher starts local emulator and game executables with your privileges;
it does not sandbox them. Use software, ROMs, and artwork from sources you trust.
Environment overrides select files to execute, so review them before running.

The launcher itself has no network listener or online service. Emulators,
Wine, and games may have their own network behavior. Do not publish remote
desktop, debugging, or emulator services to the internet.

Keep ROMs, saves, savestates, game executables, Wine prefixes, local configuration,
logs, personalized desktop entries, and backup archives out of this repository.
Use only ROMs you are authorized to use. No ROMs or Windows game files are included.

Use GitHub private vulnerability reporting for security issues, and remove
personal paths and device details from screenshots, logs, or public reports.
